# 任务栏歌词 · 微光

**v1.4.1** · EchoMusic 的 Windows 任务栏歌词插件。

在任务栏左侧显示歌曲封面与同步歌词，鼠标移入歌词区域即可切歌、暂停或收藏。支持多屏、独立字号、歌词进度遮罩和封面自动取色，保持简洁的透明外观。

## 安装

需要 **Windows x64**、系统自带的 **.NET Framework WPF**，以及 **EchoMusic 2.3.2-beta.9 或更新版本**。

### 通过插件源安装

在 EchoMusic 插件管理中添加以下插件源，安装并启用“任务栏歌词 · 微光”：

```text
https://github.com/CarsonGame/EchoMusic-TaskbarLyrics
```

### 手动安装

1. 下载本仓库，将完整的 `taskbar-lyrics` 文件夹放入 `%APPDATA%\echo-music\plugins`。
2. 在 EchoMusic 插件管理中刷新并启用插件；未出现时重启播放器。
3. 首次启用时，允许播放器启动 `bin/TaskbarLyrics.exe`。
4. 打开插件设置，修改后点击“保存并应用”。更新已安装的插件后，关闭再开启插件以加载新代码。

成品 JavaScript 和辅助程序已包含，无需自行编译。插件配置由 EchoMusic 保存，更新文件不会清除已有设置。

## 功能

- **同步歌词**：支持单行、双行，第二行可显示下一句或翻译／音译；两行可分别设置字号、文字颜色和遮罩颜色，字体使用播放器的字体列表。
- **进度遮罩与滚动**：逐字歌词按时间显色，普通 LRC 按句内进度显色；长句跟随播放进度横向滚动。暂停时停止推进，继续播放、跳转和倍速变化后同步校准。
- **歌曲封面**：显示在歌词左侧，可选矩形或圆形；圆形封面可随播放旋转，暂停时停止。鼠标放在封面上时，右侧显示当前歌名和演唱者；过长的文字独立往返滚动，暂停也可查看。移到歌词区域后恢复快捷操作。
- **悬浮快捷操作**：上一首、播放／暂停、下一首、收藏／取消收藏。收藏状态读取播放器，所有屏幕同步；按钮位置可选靠左或“随当前歌词长度居中”，按钮尺寸保持一致。
- **封面自动取色**：优先提取封面的鲜艳颜色，歌词遮罩、按钮图标和按钮栏背景分别选择自定义或封面配色。切歌时保留上次成功颜色，当前封面取色成功后再更新，避免短暂闪白。
- **多屏显示**：选择主屏幕、指定屏幕或全部屏幕，屏幕列表随连接状态更新；各屏按实际 DPI 自动适配尺寸。界面使用连续屏幕编号，主屏优先排列。
- **实时预览**：设置按功能分组，相关功能开启后才显示依赖选项；修改即时预览，保存成功通过 toast 提示。
- **悬浮播放进度条**：移入歌词区域时显示与按钮栏等宽的细进度条，不显示时间；移入进度条时加粗，在上方显示“当前播放时间 / 总时长”并隐藏按钮，移开后恢复。点击或拖动后松手跳转，可独立于快捷按钮开启。未知时长时不显示，切歌会取消尚未提交的拖动，各屏共享操作锁。
- **智能颜色对比度**：根据 Windows 任务栏明暗和按钮背景，适度调整封面自动配色，提高可读性；手动颜色保持不变。
- **切歌过渡动画**：等待新封面加载完成后渐变显示，配色平滑过渡；快速连续切歌接续当前画面，不使用过期封面。动画不影响歌词时钟，暂停时歌词进度仍冻结。

没有歌词、前奏或等待歌词加载时显示歌曲名称，双行模式同时显示歌手。没有翻译时翻译行可为空。

## 设置与默认值

新安装和“恢复默认”使用以下默认配置，已有配置继续保留。

| 分组 | 主要设置 | 默认值 |
| --- | --- | --- |
| 显示与位置 | 屏幕、宽度、左侧距离、垂直偏移、透明度 | 主屏幕；宽 360；左侧距离 12；垂直偏移 +2；透明度 0% |
| 歌词外观 | 行数、第二行内容、两行字号、字体、待歌词颜色 | 双行：当前句＋下一句；字号 16／12；跟随播放器字体；两行白色 |
| 歌词进度遮罩 | 开关、配色来源、两行自定义颜色 | 开启；使用封面配色；备用颜色 `#85DCD0` |
| 歌词外观中的视觉效果 | 智能对比度、切歌动画、过渡时长 | 两项开启；过渡 280 ms，可调 100～1000 ms |
| 歌曲封面 | 显示、矩形／圆形、圆形旋转 | 显示；矩形；旋转关闭 |
| 快捷操作 | 按钮与进度条悬浮开关、共同位置、图标配色 | 两项开启；靠左；使用封面配色 |
| 快捷操作背景 | 背景配色、透明度 | 使用封面配色；透明度 100% |
| 按钮交互反馈 | 悬停背景、按下背景及各自颜色 | 两种背景均关闭 |
| 播放行为 | 长句滚动、暂停时隐藏、全屏时隐藏 | 滚动开启；暂停不隐藏；全屏时隐藏 |

尺寸与偏移使用逻辑像素，各屏按 DPI 换算。垂直偏移范围为 −20～20：负值向上，正值向下，封面、歌词和快捷按钮一起移动；超出任务栏的部分会被裁切。

“随当前歌词长度居中”根据当前可见歌词的文字长度调整按钮栏位置，不计入封面和尾部空白；短句预留按钮所需空间。鼠标悬浮期间固定位置，便于连续操作。

按钮图标、按钮栏背景和歌词遮罩的配色互相独立。背景透明度支持 0～100%：0% 不透明，100% 完全透明；单个按钮的悬停、按下背景另有开关和颜色，按下效果优先。隐藏封面不影响自动取色；封面缺失或取色失败时保留上次成功颜色，首次取色前使用自定义颜色。

关闭功能或收起依赖选项会保留其配置。上方预览只演示外观和交互反馈，不操作真实歌曲；点击“保存并应用”后，各屏同步应用设置。

## Windows 显示行为

歌词使用透明、无边框、不抢焦点的窗口，不显示在任务栏或 Alt+Tab 列表中。歌词和封面点击穿透，悬浮按钮接收点击。窗口以所在屏幕任务栏为所属窗口，响应任务栏和开始菜单的层级变化，不向 Explorer 注入代码。

各屏跟随任务栏位置、分辨率及 DPI 变化；任务栏收起或启用全屏隐藏时，该屏歌词隐藏。副屏未启用系统任务栏时显示在屏幕底边。开始菜单不作为全屏应用处理。

插件不会替任务栏图标、天气等内容自动腾出位置。出现重叠时，请调整显示宽度和左侧距离。

## 开发与构建

插件源码位于仓库的 `taskbar-lyrics` 目录。设置界面声明在 `src/SettingsPanel.html`，原生窗口声明在 `native/LyricsWindow.xaml`。

在插件目录安装依赖、构建 JavaScript 并运行测试：

```powershell
npm install
npm run build
npm test
```

在 Windows 上构建原生辅助程序：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-native.ps1
```

原生程序为 Windows x64 / .NET Framework WPF，使用系统编译器，无需额外 NuGet 包。JavaScript 构建使用 Vue 模板编译器，运行时使用 EchoMusic 提供的 Vue。

辅助程序通过随机端口和访问令牌保护的 `127.0.0.1` HTTP 服务读取播放状态与歌词，并发送歌曲操作。封面优先由播放器读取，失败时尝试当前歌曲的原始图片地址；多屏共享缓存。插件禁用或播放器退出时关闭服务和辅助程序，连续连接失败时辅助程序也会自行退出。

诊断日志位于插件目录的 `bin/TaskbarLyrics.log`。启动失败或权限取消后，可在设置中使用“启动／重新连接”。
