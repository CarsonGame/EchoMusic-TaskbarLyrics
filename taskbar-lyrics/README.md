# 任务栏歌词 · 微光

**v1.1.0** · EchoMusic 的 Windows 任务栏歌词插件，在任务栏左侧显示封面、同步歌词与悬浮播放操作。

## 功能

- **同步歌词**：单行／双行，第二行可选下一句或翻译／音译；支持逐字进度遮罩、长歌词随播放滚动，暂停、继续、跳转和倍速同步。无歌词或前奏时显示歌名与歌手。
- **歌词外观**：两行分别调整字号、文字和进度遮罩颜色；字体使用播放器字体列表，可跟随全局设置。
- **歌曲封面**：矩形／圆形，圆形可随播放旋转，暂停时停止；悬停封面显示歌名与歌手，长文字自动往返滚动。
- **快捷操作**：悬停歌词显示上一首、播放／暂停、下一首、收藏／取消收藏；收藏状态由播放器同步，多屏共用操作状态。按钮栏可靠左或随当前歌词长度居中，关闭背景后整块按钮仍可点击。
- **悬浮进度条**：与按钮栏等宽，可独立开关。移入时加粗并显示当前时间／总时长，暂时隐藏按钮；移开后恢复。支持点击、拖拽跳转。
- **切歌信息浮层**：在按钮上方显示歌名与歌手，可仅在任务栏点击上一首／下一首时提示。支持展示时长、淡出、悬停保持、居左／居中、长文字滚动，以及独立字号和颜色。
- **浮层背景**：自定义颜色、封面配色或毛玻璃，可调整透明度、宽度、圆角与间距；隐藏封面也可使用浮层。
- **封面自动取色**：提取鲜艳颜色，歌词遮罩、按钮图标和背景分别选择自定义或封面配色；新颜色就绪前保留上一首配色，避免闪白。
- **按钮反馈**：按钮栏背景、图标独立配色；悬停与按下背景分别开关、调色，背景支持透明度调整。
- **视觉效果**：智能颜色对比度、封面与配色切歌过渡动画，可分别开关并调整过渡时长。
- **多屏与位置**：主屏、指定屏幕或全部屏幕，动态屏幕列表与 DPI 自动适配；可调宽度、左右位置、垂直偏移和整体透明度。支持暂停／全屏时隐藏，歌词与封面点击穿透，不抢焦点。
- **实时预览**：设置修改即时预览，依赖选项按需显示，保存成功以 toast 提示；各屏同步应用配置。

## 安装

需要 **Windows x64**、系统自带的 **.NET Framework WPF**，以及 **EchoMusic 2.3.2-beta.9 或更新版本**。

在 EchoMusic 插件管理中添加插件源，安装并启用“任务栏歌词 · 微光”：

```text
https://github.com/CarsonGame/EchoMusic-TaskbarLyrics
```

也可下载本仓库，将完整的 `taskbar-lyrics` 文件夹放入 `%APPDATA%\echo-music\plugins`，刷新插件管理后启用。首次启动请允许插件运行辅助程序；成品已包含，无需编译。更新文件后关闭再开启插件。

## 设置

修改后点击“保存并应用”。新安装和“恢复默认”使用项目默认配置，快照保存在 `taskbar-lyrics/default-settings.json`；已有设置继续保留。

透明度越大越透明，0% 不透明、100% 完全透明；浮层毛玻璃的透明度只控制叠色，100% 仍保留模糊。垂直偏移负数向上、正数向下。任务栏内容重叠时，可调整显示宽度和左侧距离。

## 开发

源码位于 `taskbar-lyrics`，设置界面与原生窗口分别声明在 `src/SettingsPanel.html`、`native/LyricsWindow.xaml`。

```powershell
cd taskbar-lyrics
npm install
npm run build
npm test
powershell -ExecutionPolicy Bypass -File .\build-native.ps1
```

参考：[EchoMusic 插件开发文档](https://github.com/hoowhoami/EchoMusicPlugins/blob/main/docs/plugin-development.md)。
