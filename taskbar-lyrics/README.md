## 启用

1. 将整个 `taskbar-lyrics` 文件夹放入 `%APPDATA%\echo-music\plugins`。
2. 在 EchoMusic 的插件管理中刷新列表；如果没有出现，请重启播放器。
3. 启用“任务栏歌词 · 微光”。首次启动时，EchoMusic 会询问是否允许启动 `bin/TaskbarLyrics.exe`，确认后显示歌词。
4. 点击插件的设置入口，修改后点击“保存并应用”。

## 设置

- **显示屏幕**：默认主屏幕；可选择指定屏幕或全部屏幕。列表显示连续屏幕编号、分辨率和主屏标记，修改后保存并应用；屏幕接入或断开会自动更新。
- **单行／双行**：默认单行；双行支持当前句＋下一句或当前句＋翻译／音译。
- **独立字号**：两行分别调整，上方预览实时生效；任务栏高度不足时，保留字号比例缩小。
- **文字颜色**：自动跟随 Windows 任务栏，或为每行分别设置文字颜色与已播放颜色。
- **歌词字体**：直接使用播放器 `ctx.fonts.getOptions` 字体列表，支持搜索和跟随全局字体。
- **歌词进度遮罩**：提供独立开关；有逐字时间的歌词按逐字进度显色，普通 LRC 按句内进度显色。翻译支持同步进度，下一句保持预览。
- **显示宽度、左侧距离、不透明度**：通过 EchoMusic 私有插件设置保存；实际物理尺寸按 Windows DPI 换算。
- **暂停时隐藏**：默认关闭；**全屏应用时隐藏**：默认开启。
- **启动／重新连接**：授权取消或辅助程序退出后，可重新启动。

没有歌词、前奏或切歌等待期间显示歌曲名称；双行第二行显示歌手。没有翻译时第二行可为空。长句按当前句的播放进度横向滚动，句首显示开头、句尾显示结尾；暂停冻结，跳转、倍速和歌词偏移同步校准。短句保持静止。双行翻译随当前句同步滚动，下一句保持预览。可在设置关闭滚动，此时长句使用省略号。双行字号自动适应任务栏高度。

## Windows 行为

透明、无边框、不抢焦点、不显示在任务栏或 Alt+Tab，鼠标点击直接穿透。响应任务栏层级变化，并在渲染前检查层级，避免点击任务栏后等待定时置顶；开始菜单等 Shell 窗口不判作全屏应用。各屏幕独立跟随任务栏移动、分辨率和 DPI 变化；该屏任务栏收起或该屏全屏应用时隐藏。副屏未启用系统任务栏时在该屏底边显示。默认左侧偏移为 12 个逻辑像素、宽度为 360 个逻辑像素。

歌词以对应屏幕的任务栏为所属窗口，跟随任务栏层级；没有任务栏时使用屏幕底边浮窗，不注入 Explorer 代码。不会为天气、开始菜单或固定图标重新分配位置；任务栏左侧已有内容时，请调整显示宽度／左侧距离。多屏模式下，各窗口使用同一份播放进度和歌词设置。

## 原生程序与数据

`TaskbarLyrics.exe` 为 Windows x64 / .NET Framework WPF 辅助程序，界面声明在 `native/LyricsWindow.xaml` 并嵌入可执行文件。无需安装额外 NuGet 包或管理员权限。通过随机端口、随机访问令牌的 `127.0.0.1` HTTP 服务读取当前歌词；不访问互联网，不修改系统任务栏设置。

插件禁用或播放器退出时，EchoMusic 会关闭服务并终止辅助程序；辅助程序也在连续连接失败后自行退出。诊断日志在 `bin/TaskbarLyrics.log`。

要求 EchoMusic **2.3.2-beta.9 或更新版本**。

## 构建

成品 `index.js` 和 `bin/TaskbarLyrics.exe` 已包含，可直接使用。

修改 JS／设置模板后，在该目录执行 `npm install`、`npm run build`。修改 XAML／C# 后执行 `powershell -ExecutionPolicy Bypass -File .\build-native.ps1`。原生构建使用 Windows 自带 .NET Framework 编译器。

`npm test` 验证歌词时钟、偏移、切歌、单／双行、翻译及设置边界。构建时 Vue 模板编译器使用 MIT 许可；运行时使用 EchoMusic 提供的 Vue。
